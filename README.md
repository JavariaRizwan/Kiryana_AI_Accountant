# Kiryana AI Accountant – Urdu Voice-Enabled Bookkeeping Web Application
An intelligent, localized bookkeeping platform designed for local grocery store (kiryana) owners, enabling effortless financial tracking and transaction management through natural Urdu voice commands and automated data parsing.

# Key Features & Architecture:
Urdu Voice-Powered Input: Integrates speech recognition and natural language processing to let merchants log sales, expenses, and inventory updates naturally via spoken Urdu.

Automated Bookkeeping & Ledger: Instantly categorizes transactions, updates digital ledgers, and calculates daily or monthly balances without manual data entry.

Modern Web Stack: Built with Next.js for a fast, responsive user interface and seamless server-side rendering, ensuring smooth performance on mobile and desktop browsers.

Accessibility & Localization: Designed specifically with a simple, intuitive UX tailored for non-tech-savvy merchants, bridging the digital literacy gap in local retail commerce.
